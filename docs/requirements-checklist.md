- [ ] Create 9 shirt designs.
- [ ] Support 4 shirt colors per design.
- [ ] Support sizes S, M, L, XL, 2XL at minimum.
- [ ] Track finite inventory for each design/color/size variant.
- [ ] Allow quantity selection before adding to cart.
