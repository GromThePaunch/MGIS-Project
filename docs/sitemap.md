# Sitemap

- Home / Catalog (`/index.php`)
- Item Detail (`/pages/product.php?id={product_id}`)
- Cart (`/pages/cart.php`)
- Login (`/pages/login.php`)
- Register (`/pages/register.php`)
- Profile (`/pages/profile.php`)
- About Us (`/pages/about.php`)
- Contact Us (`/pages/contact.php`)

## Shared layout elements

- Header: company name, catalog, about, contact, cart, login or profile link
- Footer: sitemap links, contact details, short company blurb

## Primary user journeys

1. Browse catalog.
2. Open item detail page.
3. Choose color, size, and quantity.
4. Add item to cart.
5. Review cart totals.
6. Log in or register.
7. Confirm billing, shipping, and mock payment data.
8. Place order.
9. Receive order confirmation email.
10. Review order in profile history.
